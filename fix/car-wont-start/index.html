My car won't start

Dead battery or bad alternator? How to check before you buy anything

Our Yukon wouldn't start for Jen and the kids at Dairy Queen. Before I bought any parts, I ran the same two tests I always run.

What I did

  1. Start with the alternator. With the engine running, put a multimeter on the battery. You want about 13 to 14 volts. Mine read 14.39, so the alternator was charging fine. Watch this part
  2. If it only reads 11 or 12 volts with the engine running, suspect the alternator first. The battery might be fine. Watch this part
  3. Charge the battery, then load test it. Hook up the tester, push the button, and watch the needle. Mine dove into WEAK and didn't come back. Official diagnosis: dead battery. Watch this part
  4. Test the new battery the same way, so you can see what a good one looks like. Watch this part

What I used

  • Schumacher battery load tester (6/12 V)
  • Innova 3320 multimeter
  • Schumacher SC1307 battery charger (85-amp engine start)
